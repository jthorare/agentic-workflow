# Setup: open decisions

1. Question: do the six steps live on a first-run page or under Settings?
   Options: a first-run page that disappears; the Settings page, always there.
   Recommended: the Settings page. Home links to it until all six are done, and a new repo adds its rows again later. Follows Linear (the onboarding checklist stays reachable from settings).
2. Question: do finished steps collapse away?
   Options: hide them; keep every row, collapsed, with its detail line.
   Recommended: keep every row so you can see what Sindri did ("approved just now", "3,100 files"). Follows Linear's checklist, which keeps ticked rows.
3. Question: is the whole workflow list shown before the hold?
   Options: a scrolling box; the full list.
   Recommended: the full list, because it is the preview you are approving. Follows HumanLayer (the whole request shown before approve).
4. Question: does the map step have a button?
   Options: a promote button; none.
   Recommended: none. The owner rule says the map builds itself, so the row only shows progress and a Retry on failure. Follows SuperPlane's integration status rows (status only, action on failure).
5. Question: where does the terminal alternative for Onyx go?
   Options: inside the Onyx row; one line under the list.
   Recommended: one line under the list, so the six rows stay about the app. Follows Linear (secondary alternatives as quiet footnotes).

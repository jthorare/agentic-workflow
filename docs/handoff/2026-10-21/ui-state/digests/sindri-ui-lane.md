## Gotchas learned

- **Builders must push.** Each item is committed red first, then the fix, and pushed (`git push origin <branch>` as its OWN command: a hook blocks any push command containing "main"). Format must exit 0 on the FINAL commit; re-run it after any style commit.
- **Builder context.** Builders run out of context (~120k). Brief them to stop at a green pushed commit and write a handoff in `digests/`. Keep briefs small; split big passes.
- **Never pkill.** Kill by PID only. Leave Temporal servers you didn't start alone (`pgrep -c -f '[t]emporal server start-dev'`). Never use `git stash` (the stash is shared across worktrees); use a WIP commit or `git diff > file`.
- **Real-app proofs run in a PRIVATE session.** Use a private Xvfb display (:99) and a private D-Bus/AT-SPI bus, through the tools in `~/.agentic-workflow/jthorare-agentic-workflow/proof/sindri-ui-u1/raw/tools/` (privsession.py guard, env.sh, session-up.sh, atspi.py, keys.py, shot.py). NEVER DISPLAY :0 or :1, and never `/run/user/1000/at-spi`: a prover once replaced the owner's AT-SPI bus. Evidence goes in `proof/<unit>/{manual-test.md,evidence.md,shots/}`. Linux AT-SPI doesn't announce live regions; that is a known limit with an owner provisional default.
- **Flaky view-model tests.** View-model unit tests have no UI dispatcher, so `ConfigureAwait(true)` continuations run on the thread pool. Tests that race across reads use `UiThread.Run` (tests/Aw.Sindri.Ui.Testing/UiThread.cs, added on #197). A test should await the operation directly instead of pushing an event and polling.
- **Avalonia accessibility.** A Border or Panel gets a NoneAutomationPeer: add `AutomationProperties.AccessibilityView=Control` and a `ControlTypeOverride`. A TextBlock's peer names itself from Text and ignores AutomationProperties.Name, so put the Name on a Control wrapper and make the TextBlock Raw (the ChordHint pattern). Live regions: set the flag before the text, never "", and announce exactly once. Focus is never lost.
- **Goldens and the fake.** Golden values are read from disk, never hard-coded. The fake and the real client share contract tests (SindriApiContract). Any lane that adds catalog rows or goldens must run Aw.Sindri.Ui.Tests.
- **Analyzers.** AW1005 (300-line files), MA0051 (40-line methods), MA0166 (`.WaitAsync(TimeSpan, TimeProvider.System, Token)`), IDE0072 (needs a scoped pragma in the lane-anchor switch). Pass one glob per `--filter-method`.
- **Lane anchors.** `LANE ANCHOR U3'` and `LANE ANCHOR U8` markers sit adjacent. U3' inserts immediately ABOVE its marker and U8 immediately BELOW its own, never between them (docs/csharp/sindri-ui.md "Lane anchors").

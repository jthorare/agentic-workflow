## 4. Rules in force (details in the handoff)
- **Builders:** up to 4 Sonnet builders per lane (owner, 2026-10-18), each in its own worktree and branch.
- **Heavy jobs:** every build and test goes through `~/.agentic-workflow/bin-r1b/heavy`, bounded with `timeout`. The box heavy cap is the memory guard.
- **Ready line:** `ready #N <sha>` goes on the FIRST line, only in ready messages.
- **Review loop:** 0 blocking and 0 issues, at most 5 runs; nits are resolved in writing.
- **Integration budget:** 90 s for the Ui integration lane. CI's LANE-PKG-001 judges; local runs on a loaded box don't count.
- **Spec PRs:** 3 /autoplan rounds before the owner reads them.
- **Never** touch the shared checkout. Kill by exact PID only. `unset TMUX` and use `tmux -L <unique>`. Never override HOME for dotnet.
- **Commit trailer** (current): `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` plus the current Claude-Session line from the system's attribution reminder. PR bodies end with 🤖 Generated plus that session link.

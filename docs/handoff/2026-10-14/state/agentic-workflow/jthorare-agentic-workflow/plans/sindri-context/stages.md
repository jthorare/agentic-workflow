  or MCP registration. Wave-0 stages are CI-only: evidence = test + check output (spec §14 round 3).

- **Spec change needed → stop and ask the owner.** Never edit another lane's spec.
- **Owner checks** (real Linear / Onyx / work repo): stage owner writes `owner-check.md`, the owner runs it.

# PR 2: Open every verb to agent sessions

## Summary
Most of the "89 refusals" are not gates. 44 `AuthRefused` returns say `"<Service> needs a caller"` (a null caller
context: nothing to attribute the write to); those stay. The real gates are small: (1) the authorization table
(`Authorization.cs:21-31`) which already lets an owner-started session do every class and only narrows a **launched**
session (no Pause/Decision/Desk/Protected), (2) `NeedsTerminal: true` on three catalog rows plus every Protected row, (3) about a dozen
per-service and per-verb `if (session) refuse` checks. This PR removes those three, keeps SND-AUTH-003 (launch secret,
`AgentReportAuthority.cs`), and makes sure every write records `By` (owner or `session:<id>`).
Rollback: revert; no data changes.

  and `CallersFor(row)` renders the Who column in `sindri commands`/the command-list golden.

  has its own refusal for a launched session answering a desk step: it dies with PR 3, nothing to change here.

  `LaunchSecrets.cs:13`.
- Tests that encode the old rule and must flip: Catalog/LaunchedSessionAuthorizationTests, Catalog/IndexVerbAuthorizationTests,
  Projects/ProjectSessionRefusalTests, ContextCalls/IndexVerbsTests, OnyxPurge/OnyxPurgeCommandTests,

# PR 13: Memory stores and facts

## Summary
A memory is a named store; a fact is short text with tags, an optional expiry and where it came from (workflow, run, item,
session). Recall embeds the query with the model Sindri already pins for the code index (`nomic-embed-text` through
Ollama, `context/code-index.lock`) and ranks by cosine similarity at three levels (loose, balanced, strict). Without the
model it falls back to keyword ranking and says so in the answer (`mode: keyword`). Writes deduplicate: a fact
similar to an existing one with the same tags refreshes it (`refreshed_at`) instead of adding a row; the threshold is a
named constant with a calibration test over a fixture set of near and far pairs. Exact search, no ANN index.
Picker labels: `memory_search` is Recall, `memory_write` is Remember, `memory_forget` is Forget (labels only; type names do not
change). The blocks themselves land in the follow-up that comes after PR 6 and PR 7.
Rollback: revert.

Dependency catch: deps.yaml says Sindri reaches `Aw.Embeddings` from Host only (a compose edge into a tier-0 package is
illegal and Aw.Sindri.Features is at the 4-project-reference limit). So the port `IMemoryEmbedder` is in Core and its
adapter is in Host beside `ContextVectors/EmbeddingsChunkEmbedder.cs`, exactly as Context's vector ports are bound.

## Graph context
- `IEmbedder` is used today by Host `EmbeddingsQueryEmbedder`/`EmbeddingsChunkEmbedder` for Context and the code index; both
  share one Ollama and one pinned digest, so this PR adds load, not a new dependency. A missing model is the existing doctor row
  (`OllamaRecordEmbedderProbe.cs`); the memory fallback uses the same probe.
- Callers: memory blocks (this PR), `prompt`/`run_agent` recall, MCP and CLI, the app list page (PR 18).
- The name `memory_search` is also the idea behind other tools an owner's session may have loaded; docs say "Sindri memory
  stores" and the tool descriptions say so to avoid a model picking the wrong server's tool.
- Data lives in the ledger db (source of truth, not rebuildable from events), backed up by the migration runner like the
  rest of it.
- Untrusted text: recalled facts may hold text an agent wrote from a connection; they are fenced when put into prompts.

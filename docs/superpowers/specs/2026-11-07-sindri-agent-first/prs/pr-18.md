# PR 18: Connections, memory, toolkits and resources pages

## Summary
Each area gets a list page whose rows and actions are exactly what its MCP tools return and do (G8): nothing in the app
that an agent cannot do. **Connections**: name, kind, status chip (`connected`, `needs-sign-in`, `error`), last refresh,
"Sign in again", Test, Remove, Add (a preset picker, then the browser consent opens; a pasted-key form for `rest` and `cli`).
**Memory**: stores with fact counts, a search box showing `semantic` or `keyword` mode, facts with provenance and tags,
write and forget. **Toolkits**: state, last build, Build / Start / Stop / Pause, the call log. **Resources**: owner, kind,
name, size against its limit, Purge (refused while active, with the reason shown). Connections is a tab; the others are
not tabs (`G` chords, the palette and System links, as the Jobs page is today: PageId.cs "Jobs: Not a tab"), so the tab bar
does not grow by four.
Rollback: revert.

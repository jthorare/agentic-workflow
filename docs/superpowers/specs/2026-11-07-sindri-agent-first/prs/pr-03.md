# PR 3: Remove recipes, RecipeWorkflow and the factory stations

## Summary
Delete the engine that interprets YAML recipes and everything that only exists for the spec-to-PR line. Keep what the
design keeps: the item model, the ledger, the launcher and agent runtime (Agent*.cs in Aw.Sindri.Workflows,
Core/Launch, Infrastructure/Launch), the sandbox, takeover/handback, the Temporal host, the context engine, the code
index, Work / Projects / Reviews, the Linear hub. Instances in flight are cancelled with one ledger note
(`workflow.retired`), no migration. The solution must build with `-warnaserror` and the unit and integration lanes pass.

**Do this PR as two commits (or split it, see the summary).** Commit 1 is a pure move with no behavior change: the
types the launcher shares with the engine (`LaunchId`, `RunToken`, `InstanceAddress`, `ItemKey`, `StepRuntime`,
`StepArgs`, all in `Aw.Sindri.Core.Workflow.Engine`) move to `Aw.Sindri.Core.Launch`/`.Runs` (new), because 359 Features,
117 Core, 92 Infrastructure and 66 Host files import `Aw.Sindri.Core.Workflow*` and `LaunchRequest.cs:22` itself
takes `InstanceAddress` and `RunToken`. Commit 2 deletes.

## Graph context
- Direct deleters are easy; the hidden dependents are the problem. `Core.Workflow.Engine.LaunchId` is used by 193
  files, `InstanceAddress` by 139, `ItemKey` by 43, `RunToken` by 38. Launch (Core/Launch 89 files, Infrastructure/Launch 127)
  and Sessions (Core/Sessions 70) use them; hence commit 1.
- Core/Views projections that read engine events: `ItemsProjection.Engine.cs`, `NeedsYouProjection.Engine.cs:17`,
  `RecipeStatsProjection.cs:13` (+ `0006_recipe_stats.sql` in Views/Migrations): PR 4 owns those; this PR leaves them
  compiling on the history types.
- Callers that survive: SchedulerHost.cs:25 (services), SweepLostSessions, Features/Sessions, GetLaunch*, Host/Composition.cs:27
  registrations (`AddSindriWorkflows` at SindriWorkflowsServiceCollectionExtensions.cs:32 loses the recipe activities).
- `NeedsYouRows.Recipes.cs`, `.Engine.cs`, `InstanceWords.*` feed the Needs-you page: replaced by graph rows in PR 6/9.
- UI keeps compiling because it only talks HTTP (0 `Core.Workflow` imports); its pages come out in PR 4.
- Safety net for the sweep: `Aw.Architecture.Tests`, `check-deps.mjs`, PublicAPI.*.txt for all four Sindri assemblies.

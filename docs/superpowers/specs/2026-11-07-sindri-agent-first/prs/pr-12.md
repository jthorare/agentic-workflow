# PR 12: Handoff inbox

## Summary
Pull, not push (D7). A `rest` connection with an `inbox` role points at an HTTP API with three calls: **list offers** for
this owner, **claim** one atomically (a lost race is 409 and nothing starts), **submit** a result (markdown and links).
Sindri polls it with PR 11's loop. A claimed offer becomes an **item** carrying the offer's payload (title, repo, branch,
prompt, links) and starts any workflow whose Connection event trigger (`connection_event`, event kind `inbox.offer`) on that inbox-role connection matches. When that run ends, its declared `outputs` are
submitted back. A local endpoint `POST 127.0.0.1:<port>/sindri/handoff` creates the same kind of item for apps and
scripts on the machine. The contract is a checked-in OpenAPI file with a conformance test fixture, so a workplace system
can implement it from the file alone.
The conversation blocks (Read conversation, Add to conversation, Link thread) land here too, with one conversation port per
connection kind (a Slack thread, a GitHub PR's comments, a Linear issue's comments, a Sindri item's own thread).
Design note: Part 3 lists four connection kinds but then says "an `inbox` connection". This card keeps four kinds and
makes inbox a role on a `rest` connection; the owner can overturn that on the issue.
Rollback: revert.

## Graph context
- Items: `CreateItemService` (Features/CreateItem, line 24) is the only item writer for these; `view_item_links` (PR 4) gets a
  `handoff` link kind so the Work page can show the source and the run.
- Triggers: workflows on an inbox-role Connection event are looked up through the same active-workflow index as every other `connection_event` (PR 11).
- Loopback endpoints already pass `LoopbackGuard`/`LoopbackBinding`; the per-start token is the same one the app uses, so a
  stolen script token equals owner access on this machine (D2 accepts that, risk 1).
- Occurrence = claim id means a redelivered claim cannot start a second run (PR 6 duplicate refusal).
- Not touched: Reviews, Projects, Linear hub.
